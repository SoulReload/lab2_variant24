# Лабораторная работа № 2 — вариант 24

**Тема варианта:** анализ динамики показателей финансовой отчётности предприятий холдинга.

Проект сохраняет последовательность заданий по Django, HTML-шаблонам и CSS, но использует примеры финансовых показателей вместо абстрактных строк таблицы.
Все организации, суммы, коэффициенты важности и курсы валют в проекте вымышлены и приведены только для учебной демонстрации.

## Запуск в Windows PowerShell

Откройте PowerShell в корневой папке `lab2` (там, где находятся `requirements.txt` и `README.md`) и выполните:

```powershell
python -m pip install -r requirements.txt
cd firstwebpage
python manage.py migrate
python manage.py check
python manage.py test flatpages
python manage.py runserver
```

В корневой папке проекта будет создан локальный файл SQLite `firstwebpage/db_project_name`.
Он намеренно исключён из Git правилами `.gitignore` и не должен загружаться в публичный репозиторий.

## Адреса учебных этапов

| Адрес | Содержание |
|---|---|
| `http://127.0.0.1:8000/stage1/` | Первый этап: `Привет, Мир!` с `text/plain` |
| `http://127.0.0.1:8000/hello/` | Тот же текст с явно указанным `text/plain` |
| `http://127.0.0.1:8000/hello-plain/` | Тот же текст без `content_type`; Django использует тип по умолчанию |
| `http://127.0.0.1:8000/` | Базовый зелёный шаблон: 4 столбца, 5 строк данных |
| `http://127.0.0.1:8000/table-stage/` | Этап после задания по таблице: 6 столбцов, 7 строк данных, границы и `h4` |
| `http://127.0.0.1:8000/static-handler/` | Доработанный шаблон с CSS, изображением и таблицей обменных курсов (условные данные) |

## Как содержание связано с вариантом 24

- В таблицах используются условные предприятия холдинга, отчётные периоды и финансовые показатели.
- На втором этапе таблицы добавлены валюта и коэффициент важности показателя.
- На стилизованной странице показана отдельная таблица условных курсов RUB, USD и EUR.
- Значения не являются реальными финансовыми данными или актуальными валютными котировками.
