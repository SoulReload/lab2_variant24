## Цель работы

Освоить базовые представления Django, возврат текстовых HTTP-ответов, работу с HTML-шаблонами и подключение статических файлов. Примеры содержимого адаптированы под предметную область варианта 24 — финансовую отчётность предприятий.

## Ход работы

1. Создан проект Django `firstwebpage` и приложение `flatpages`.
2. Реализован начальный этап с ответом `Привет, Мир!` и типом `text/plain`. Для сохранения этапа добавлен отдельный адрес `/stage1/`.
3. Добавлен адрес `/hello/` с тем же текстом и явно указанным типом `text/plain`.
4. Добавлен адрес `/hello-plain/`, где `HttpResponse` вызывается без параметра `content_type`; Django использует тип ответа по умолчанию.
5. Подключён базовый шаблон `index.html`. На главной странице используется зелёный фон и таблица с 4 столбцами и 5 строками данных. Пример содержит вымышленные предприятия, периоды, финансовые показатели и значения.
6. Создан промежуточный шаблон `table_stage.html`, в котором добавлены два столбца (валюта и коэффициент важности), две строки данных, границы таблицы и заголовки списков уровня `h4`. Таблица содержит 6 столбцов и 7 строк данных.
7. Создан и дополнен шаблон `static_handler.html`: подключены CSS и локальное изображение высотой 30 px, задан шрифт с засечками для `h1`, изменён размер `h4`, ширина таблиц установлена в 100%. На странице также показаны условные учебные валютные курсы.
8. Созданы правила `.gitignore`, исключающие локальную базу данных, файлы окружения и временные файлы Python из публикации.

## Сравнение типов HTTP-ответа

- `/hello/` возвращает `Привет, Мир!` с `Content-Type: text/plain; charset=utf-8`.
- `/hello-plain/` возвращает тот же текст без явного указания типа, поэтому Django по умолчанию устанавливает `text/html; charset=utf-8`.
- `/stage1/` сохраняет демонстрацию исходного этапа задания, когда корневой адрес первоначально возвращал простой текст; после перехода к шаблонам `/` обслуживает `index.html`.
