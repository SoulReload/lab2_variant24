## Цель работы

Изучить обработку HTTP-запросов в Django, создание шаблонов HTML, настройку маршрутов и подключение статических файлов CSS и изображения.

## Ход работы

1. Создан проект Django `firstwebpage` и приложение `flatpages`.
2. Реализован начальный текстовый ответ `Привет, Мир!` с типом `text/plain`. Этот исторический этап сохранён по адресу `/stage1/`, поскольку позже корневое представление `/` переключается на HTML-шаблон.
3. Создан адрес `/hello/`, возвращающий тот же текст с явно указанным типом `text/plain`.
4. Создан адрес `/hello-plain/`, возвращающий ту же строку без `content_type`. Django устанавливает тип ответа по умолчанию `text/html; charset=utf-8`.
5. Создан базовый шаблон `index.html`. На странице зелёный фон, заголовки, маркированный и нумерованный списки, таблица с четырьмя столбцами и пятью строками данных.
6. Сохранён промежуточный этап `table_stage.html`: к таблице добавлены два столбца и две строки данных (итого шесть столбцов и семь строк данных), заданы границы, подписи обоих списков сделаны заголовками четвёртого уровня (`h4`).
7. На основе этого состояния подготовлен `static_handler.html`. В нём подключены статический CSS-файл и локальное изображение высотой 30 px; для `h1` задан шрифт с засечками, изменён размер `h4`, ширина таблицы установлена в 100%.
8. Добавлены автоматические тесты маршрутов, типов HTTP-ответов, количества строк и столбцов и наличия статических ресурсов.

## Сравнение типов HTTP-ответа

- `/hello/`: `Content-Type: text/plain; charset=utf-8`.
- `/hello-plain/`: `Content-Type: text/html; charset=utf-8` по умолчанию.

В обоих случаях тело ответа — `Привет, Мир!`; различается заголовок `Content-Type`.

## Адреса страниц

- `/stage1/` — начальный текстовый этап.
- `/hello/` — текст с явно указанным `text/plain`.
- `/hello-plain/` — текст с типом ответа по умолчанию.
- `/` — базовая зелёная HTML-страница 4×5.
- `/table-stage/` — таблица 6×7 с границами и заголовками списков `h4`.
- `/static-handler/` — копия с дальнейшими CSS-изменениями и изображением.
